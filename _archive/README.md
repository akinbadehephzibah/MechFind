# Archive

`mechfind-prototype.html` is the earlier single-file prototype of the site
(dark theme, gradients, JavaScript hash router). It was never committed to
git, so it is kept here rather than deleted.

The live site superseded it: separate HTML pages sharing
`../assets/css/style.css`, a white ground, no gradients, and no
JavaScript at all.

Note that this prototype references its own inline styles and remote
images, so it does not depend on anything in `assets/`.
